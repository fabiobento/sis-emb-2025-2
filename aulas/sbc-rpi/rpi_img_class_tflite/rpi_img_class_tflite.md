
Para instalar as bibliotecas necessárias para o roteiro de laboratório de classificação de imagens usando TensorFlow Lite no Raspberry Pi, execute os seguintes comandos:
```bash
pip3 install numpy==1.24.2
```

Para exibir imagens
```bash
pip3 install matplotlib
```

Para processamento de imagens
```bash
sudo apt install libjpeg-dev zlib1g-dev -y
pip3 install Pillow==11.3.0
```
