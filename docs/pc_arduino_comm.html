O Que é Comunicação Serial?

Imagine uma conversa por um único fio, onde cada palavra é enviada letra por letra, em sequência. É exatamente isso que a comunicação serial faz. O Arduino "fala" através do cabo USB, e nosso script Python "escuta" para capturar a mensagem.

A regra mais importante é que ambos devem conversar na mesma velocidade. Essa velocidade, medida em bits por segundo, é chamada de Baud Rate. Se as taxas forem diferentes, a comunicação falhará.

Mão na Massa: Nosso Projeto

1 Pré-requisitos

  • ✓ Python 3 e a biblioteca `pyserial` instalados.
  • ✓ Um Arduino conectado via USB.
  • ✓ O Arduino deve estar rodando o código que envia dados no formato `x,y,z`.

2 Encontre sua Porta Serial

Precisamos saber "onde" o Arduino está conectado. Use o comando correspondente ao seu sistema operacional no terminal:

# Em Linux ou macOS

$ ls /dev/ttyACM* ou ls /dev/ttyUSB*

# Em Windows, verifique no Gerenciador de Dispositivos (Portas COM & LPT)
