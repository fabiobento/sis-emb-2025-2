O "Cérebro": O Modelo Edge Impulse

O Edge Impulse nos permite treinar um modelo de classificação e exportá-lo como um único arquivo executável: o .eim.

Este arquivo contém toda a "inteligência": a pipeline de processamento de sinal (DSP) e a rede neural treinada. Nosso script Python simplesmente carrega este arquivo e o utiliza para fazer previsões.

# Baixe seu modelo treinado com o CLI

$ edge-impulse-linux-runner --download modelfile.eim


# Execute seu script, passando o modelo

$ python3 classify.py modelfile.eim
