Janela Deslizante para Análise de Dados

Dando contexto aos dados de sensores em tempo real.

Por Que Olhar Para o Contexto?

Dados de sensores, como um acelerômetro, chegam como um fluxo contínuo. Analisar uma única amostra isolada não nos diz muito sobre o movimento real. Foi um tremor rápido ou o início de um gesto longo? Para entender, precisamos olhar para um **"pedaço" de tempo**, ou uma **janela**, de dados.

O Conceito: Janela Deslizante

📥

1. Coleta

Acumulamos um número fixo de amostras de dados em uma lista ou buffer.

⚙️

2. Processamento

Quando a janela está cheia, executamos nossa lógica (ex: extrair features, classificar).

➡️

3. Deslize

Descartamos os dados mais antigos e mantemos os mais recentes para a próxima coleta.

Parâmetros Chave

WINDOW_SIZE

O tamanho total da janela. Quantas amostras precisamos coletar antes de processar.

STRIDE (Passo)

Quantas das amostras mais antigas descartamos após o processamento. Um `STRIDE` menor que o `WINDOW_SIZE` cria sobreposição, garantindo que nenhum evento seja perdido entre as janelas.

Demonstração Interativa

Configuração:

WINDOW_SIZE = 10
