Extração de Features de Aceleração

Transformando dados brutos em informação útil.

De Texto a Significado

No último laboratório, aprendemos a ler os dados do Arduino. Mas recebemos apenas uma string de texto, como "1.23,-0.45,9.81". Para qualquer análise, visualização ou Machine Learning, precisamos transformar esse texto em **características (features)**: variáveis numéricas que representam o movimento real.

// Dado Bruto (String)
"1.23,-0.45,9.81"
↓
// Features Extraídas (Floats)
acc_x
1.23
acc_y
-0.45
acc_z
9.81

O Processo de Extração

📡

1. Leitura e Decodificação

Lemos a linha de dados da porta serial e a convertemos de bytes para uma string de texto legível (UTF-8).

🔍

2. Validação e Divisão

Verificamos se a string tem o formato esperado. Se sim, a dividimos usando a vírgula como delimitador, criando uma lista de strings.

🔢

3. Conversão e Atribuição

Convertemos cada string da lista para um número (float) e atribuímos a uma variável nomeada, como `acc_x`, `acc_y` e `acc_z`.
